# 📊 Bank Loan Risk Analytics Dashboard

An end-to-end Data Analytics project leveraging SQL and Power BI to analyze loan performance, borrower risk profiles, and default patterns. The project focuses on identifying high-risk customer segments and generating actionable insights through interactive dashboards.

---

## 🎯 Project Objective

The objective of this project is to:

- Analyze borrower and loan characteristics.
- Measure loan default risk across customer segments.
- Identify factors contributing to loan defaults.
- Build an interactive Power BI dashboard for business decision-making.
- Demonstrate SQL analytics and data visualization skills.

---

## 📂 Dataset Information

**Dataset:** Credit Risk Dataset

**Total Records:** 32,581+

**Key Features:**

- Borrower Age
- Annual Income
- Home Ownership
- Employment Length
- Loan Amount
- Interest Rate
- Loan Purpose
- Loan Grade
- Credit History Length
- Loan Status (Default / Non-Default)

## 🔍 Key Business Insights

- Lower loan grades exhibit significantly higher default rates.
- Borrowers with lower income levels are more likely to default.
- Certain loan purposes contribute disproportionately to overall risk.
- Interest rates increase as borrower risk increases.
- Home ownership status impacts repayment behavior.
